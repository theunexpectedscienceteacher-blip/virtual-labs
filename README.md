# 7th Grade Science Virtual Labs

Each lab lives in its own folder (for example `rescue-run/index.html`). The home page `index.html` lists every lab.

## Add a new lab
1. Click **Add file → Create new file**.
2. Type the folder and file name, e.g. `new-lab/index.html`, and paste the lab's HTML.
3. Commit, then edit the top-level `index.html`: copy one `<a class="lab">` block and change the folder name, title and description.

The site updates on its own about a minute after each commit.
